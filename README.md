# FourPin Coding - Web Developer App

🎉 **Welcome to your first day on GitHub!** 🎉

FourPin Coding is a complete, fully-functional web developer application built with vanilla HTML, CSS, and JavaScript. Perfect for beginners and experienced developers alike!

## ✨ Features

### Core Functionality
- **Live Code Editor** - Three separate editors for HTML, CSS, and JavaScript
- **Real-time Preview** - See your code changes instantly in the live preview
- **Auto Refresh** - Toggle automatic preview updates on/off
- **Dark/Light Mode** - Switch between dark and light themes
- **Code Persistence** - Your code is automatically saved to browser storage

### User Experience
- 🎨 Beautiful gradient UI with modern design
- ⌨️ Keyboard shortcuts (Ctrl+S to save, Ctrl+R to refresh)
- 📱 Fully responsive design (works on desktop, tablet, mobile)
- 💾 Local storage integration for code saving
- 🔄 Reset functionality to restore default code
- 🌈 Smooth animations and transitions

## 🚀 How to Use

1. **Open the App** - Simply open `index.html` in your web browser
2. **Write Code** - Type HTML, CSS, and JavaScript in their respective editors
3. **See Results** - Watch the live preview update in real-time
4. **Save Your Work** - Code is automatically saved to your browser
5. **Toggle Features** - Use the buttons in the header to:
   - Switch themes (🌙/☀️)
   - Toggle auto-refresh (🔄)
   - Reset code (↻)

- Persists across browser sessions

## 🔧 Technical Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Storage**: Browser LocalStorage API
- **Preview**: Iframe with srcdoc
- **No Dependencies**: Pure vanilla code, no frameworks!
